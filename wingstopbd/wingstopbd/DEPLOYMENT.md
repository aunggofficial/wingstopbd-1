# Wing Stop BD - Quick Deploy to Vercel (5 Minutes)\n\n## Fastest Way to Get Your Website Live\n\n### Step 1: Create GitHub Repository (2 minutes)\n\n```bash\n# Create folder\nmkdir wingstopbd-website\ncd wingstopbd-website\n\n# Initialize git\ngit init\n\n# Copy all frontend files here\n# (App.tsx, pages, components, styles, package.json, etc.)\n\n# Create .gitignore\necho \"node_modules/\" > .gitignore\necho \"dist/\" >> .gitignore\necho \".env\" >> .gitignore\n\n# Commit\ngit add .\ngit commit -m \"Initial commit: Wing Stop BD website\"\n```\n\n### Step 2: Push to GitHub (1 minute)\n\n1. Go to https://github.com/new\n2. Create new repository: `wingstopbd`\n3. Copy the commands shown:\n\n```bash\ngit remote add origin https://github.com/YOUR_USERNAME/wingstopbd.git\ngit branch -M main\ngit push -u origin main\n```\n\n### Step 3: Deploy to Vercel (2 minutes)\n\n1. Go to https://vercel.com/new\n2. Click \"Import Git Repository\"\n3. Paste: `https://github.com/YOUR_USERNAME/wingstopbd.git`\n4. Click \"Import\"\n5. Click \"Deploy\"\n\n**Done! Your site is live at:**\n```\nhttps://wingstopbd.vercel.app\n```\n\n---\n\n## Add Custom Domain (Optional)\n\n1. Go to your Vercel project settings\n2. Click \"Domains\"\n3. Enter your domain: `wingstopbd.com`\n4. Update DNS at your domain registrar:\n   - Type: CNAME\n   - Name: www\n   - Value: cname.vercel-dns.com\n\n**SSL certificate is automatic!**\n\n---\n\n## Deploy Backend (Optional)\n\n### Use Railway.app (Easier than Heroku)\n\n1. Go to https://railway.app\n2. Click \"New Project\"\n3. Select \"Deploy from GitHub\"\n4. Select your backend repository\n5. Add PostgreSQL plugin\n6. Set environment variables\n7. Deploy!\n\n**Backend URL:** `https://your-app.railway.app`\n\n---\n\n## Update Your Frontend\n\nUpdate the API URL in your frontend code:\n\n```typescript\n// src/pages/Home.tsx or wherever you make API calls\nconst API_URL = 'https://your-app.railway.app';\n```\n\nThen push to GitHub:\n\n```bash\ngit add .\ngit commit -m \"Update API URL\"\ngit push origin main\n```\n\n**Vercel automatically redeploys!**\n\n---\n\n## Verify Your Deployment\n\n```bash\n# Check frontend\ncurl https://wingstopbd.vercel.app\n\n# Check backend (if deployed)\ncurl https://your-app.railway.app/api/menu\n```\n\n---\n\n## Monitoring\n\n### Vercel Dashboard\n- https://vercel.com/dashboard\n- View deployments\n- Check logs\n- Monitor performance\n\n### Railway Dashboard\n- https://railway.app/dashboard\n- View logs\n- Monitor database\n- Check metrics\n\n---\n\n## Common Issues\n\n### Build Fails\n\n**Solution:** Check Vercel logs\n```\nProject Settings → Deployments → Click failed deployment → View logs\n```\n\nMost common: Missing dependencies\n```bash\nnpm install\ngit add package-lock.json\ngit commit -m \"Update dependencies\"\ngit push origin main\n```\n\n### API Not Connecting\n\n**Solution:** Update API URL\n```typescript\n// Make sure this matches your backend URL\nconst API_URL = process.env.VITE_API_URL || 'http://localhost:3001';\n```\n\n### Database Connection Error\n\n**Solution:** Check environment variables in Railway\n- Go to Railway project\n- Click PostgreSQL\n- Copy connection string\n- Add to backend environment variables\n\n---\n\n## Next Steps\n\n1. ✅ Website is live\n2.
